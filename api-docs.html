Enquiry API

This is the form backend behind WasteMates' quote/enquiry forms. It's documented here for API discovery — full machine-readable spec at /openapi.json.

POST /send-enquiry.php

Accepts a multipart/form-data submission and dispatches it to the WasteMates team by email, Telegram, and Discord. There is no JSON response — the endpoint always returns 303 See Other and redirects back to the site, whether the submission succeeded, failed validation, or was empty.

Fields

FieldTypeNotes
namestringEnquirer's full name
mobilestringContact phone number
emailstringContact email
suburbstringJob location suburb
contact_preferencestringe.g. "Phone" or "Email"
jobstringe.g. "Household rubbish removal"
detailsstringFree-text job description
photos[]file (repeatable)Up to 8 photos, 6MB each, 15MB combined. jpeg/png/webp/gif/heic/heif only
_redirectstringOne of index.html, contact.html, pricing.html. Defaults to contact.html
_sourcestringLabel for which on-site form this came from

At least one of name, mobile, or email is required — a submission with none of the three is silently dropped.

Example

curl -i https://wastemates.com.au/send-enquiry.php \
  -F "name=Jordan Smith" \
  -F "mobile=0412345678" \
  -F "email=jordan@example.com" \
  -F "suburb=Croydon" \
  -F "job=Household rubbish removal" \
  -F "details=Old couch and mattress in the garage" \
  -F "_source=API docs example"

Response

StatusMeaning
303 See OtherAlways returned. Location header points back to the originating page with ?sent=1 appended.

This endpoint exists to serve WasteMates' own site forms — it isn't a general-purpose public API, but the contract above is stable and safe to call directly (e.g. from another WasteMates-owned surface or an automated agent submitting a lead on a visitor's behalf).
